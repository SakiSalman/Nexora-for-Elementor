## Not a sidebar control

| Item | Why |
| --- | --- |
| Case slide copy, impact tab copy, framework tab labels, pricing tab labels | Printed by the existing widget script. The scripts were not changed. |
| Decorative inline SVG icons and symbol glyphs | They are markup, not a separate content property. |
| Link `target` and `rel` | The link control edits `href` only, so the original new-tab behavior stays. |
| Cards whose inner structure differs | A featured card with a checklist is not the same item shape as a plain card, so each keeps its own controls instead of one repeater that would hide fields. |
