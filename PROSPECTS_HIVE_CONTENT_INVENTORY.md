## Script-owned copy

These visible strings are not in the HTML. They are rendered by the existing widget script from its data arrays. The scripts were not changed, so these values stay on the original copy.

| impact | Tab label, title, body, points | `IMPACT` in `nexora-ph-impact.js`, printed through `{{ impact.* }}` |
| framework | Tab label and subtitle | `FW` in `nexora-ph-framework.js`, printed through `{{ t.label }}` |

## Not given a control

| Item | Why |
| --- | --- |
| Decorative inline SVG icons | The design draws them as markup, not as an icon-library icon. Replacing the SVG would change the markup. |
| Symbol-only glyphs such as `→`, `✓`, `★`, and `▶` | They are not words or numbers. |
| `target` and `rel` on links | The URL control replaces `href` only. New-tab and nofollow behavior stays on the original attributes. |
| Process step rows as one repeater | The rows alternate image-left and image-right, so the field order is not the same. Each step’s text, image, and alt is still its own control. |
| Outer cards that contain an inner list | Elementor cannot nest repeaters. The inner list is the repeater. The card heading and description stay individual controls. |
| Aria-hidden marquee copies with an empty `alt` | Those chips are repeater items so the loop length stays the same. An empty alt is not a second text control. |
